# Espaço Ysa Estética

Site institucional desenvolvido para apresentar uma clínica de estética com uma identidade visual elegante, navegação clara e estrutura responsiva. O projeto foi criado como exercício de interface e organização de uma aplicação web em React e TypeScript.

## Objetivos do projeto

- Apresentar a marca e seus serviços em uma interface organizada.
- Criar uma navegação simples para diferentes seções do site.
- Trabalhar tipografia, cores e hierarquia visual.
- Adaptar a experiência para diferentes tamanhos de tela.
- Praticar a separação entre cliente, servidor e arquivos compartilhados.

## Tecnologias

| Tecnologia | Uso |
| --- | --- |
| React | Construção da interface |
| TypeScript | Tipagem do projeto |
| Vite | Desenvolvimento e build |
| Tailwind CSS | Estilos e responsividade |
| Express | Servidor da aplicação |
| pnpm | Gerenciamento de dependências |

## Como executar

Pré-requisitos: Node.js 20 ou superior e pnpm.

```bash
git clone https://github.com/Raydev15/espaco-ysa-estetica.git
cd espaco-ysa-estetica
pnpm install
pnpm dev
```

Para gerar uma versão de produção:

```bash
pnpm build
pnpm preview
```

## Estrutura do projeto

```text
client/       # Entrada da interface e arquivos do cliente
server/       # Servidor da aplicação
shared/       # Constantes e estruturas compartilhadas
patches/      # Ajustes de dependências
```
